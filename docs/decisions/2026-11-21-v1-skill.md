# Decision: FifthNine version 1 is a standard plus a skill

Date: 21 November 2026
Status: Proposed, awaiting CEO approval

## Context

On 21 October 2026 the scope was locked to an offline scanner with no mandatory AI model (see `docs/fifthnine/DECISIONS.md` and `docs/fifthnine/PHASE1_IMPLEMENTATION_CONTRACT.md`). That scanner is still in development.

## Decision

For version 1, that scope lock is replaced. FifthNine version 1 is:

- an open reliability standard, `skill/fifthnine/FIFTHNINE.md` (16 checks across eight factors), and
- a skill, `skill/fifthnine/SKILL.md`, that a team's AI coding agent follows to score a repository against the standard and print a one-page scorecard.

## What stays

The existing engine under `src/` and its tests stay where they are, unchanged. It is described as the "deterministic engine, in development". Pull requests 8 and 9 stay open and are outside this release.

## Consequences

- Version 1 needs an AI coding agent to run. The code stays inside the agent the team already uses.
- Because a model does the reading, two runs can disagree. The skill requires a file and line for every Pass and Fail, and each release is tested by running the skill twice on the same commit.
- A standalone command, pipeline integration, score history and dashboards are out of scope for version 1.
